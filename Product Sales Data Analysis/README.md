This repository contains a Jupyter notebook for **Product Sales Data Analysis**, where various analyses are performed on a Superstore dataset to uncover insights about sales performance, profitability, and customer behavior.

Manually install the following libraries:

- pandas (for data manipulation)
- numpy (for numerical operations)
- matplotlib (for creating plots)
- seaborn (for advanced visualizations)
- Jupyter (to run the notebook)

1. **Run the Notebook**: Open the `Product Sales Data Analysis.ipynb` Jupyter notebook and execute the cells one by one.
2. **Data Analysis**: The notebook includes various analyses, such as:
   - Identifying the **most selling products**
   - Discovering the **top 10 products by sales**
   - Analyzing **profitable products**
   - Exploring **categories and subcategories**
   - **Customer segmentation** and profitability
   - Analyzing **shipping modes** and **regions**
   - Insights into **yearly and monthly sales**

3. **Visualizations**: The analysis includes several **data visualizations** using `matplotlib` and `seaborn`, including bar charts, line plots, and heatmaps, to provide insights into the data.

## File Descriptions

### `Product Sales Data Analysis.ipynb`

This Jupyter notebook performs an in-depth analysis of a Superstore dataset. The analysis covers various aspects of the sales data, such as:

- **Product Performance**: Which products are selling the most and which are the most profitable.
- **Category Analysis**: Total sales and profitability by product category and subcategory.
- **Customer Segmentation**: Which customer segments are generating the most profit.
- **Market Insights**: Analysis by country, shipping mode, and region.
- **Time-based Analysis**: Sales trends over the years and months.

### `superstore_sales.xlsx`

This is the dataset used in the analysis, containing historical sales data, including product information, sales values, customer details, and shipping modes.
