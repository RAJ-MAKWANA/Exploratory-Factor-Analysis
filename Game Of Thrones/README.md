# Game of Thrones Data Analysis

This repository contains a Jupyter notebook for analyzing various aspects of the popular TV show *Game of Thrones* using data analysis techniques. The notebook explores different insights from the show, including but not limited to character analysis, relationships, and trends across various seasons.


## Installation

Manually install the libraries:

- pandas (for data manipulation)
- numpy (for numerical operations)
- matplotlib (for creating plots)
- seaborn (for advanced visualizations)
- jupyter (to run the notebook)

---

## Usage

1. **Run the Notebook**: Open the `GameOfThrones-EFA.ipynb` Jupyter notebook and run the cells sequentially.
2. **Data Exploration**: The notebook covers multiple analyses, such as:
   - Data cleaning and preprocessing
   - Counting observations and generating bar plots
   - Visualizing different trends and statistics
3. **Interact with the Analysis**: Modify the dataset or the analysis to further explore different aspects of the *Game of Thrones* universe.

---

## File Descriptions

### `GameOfThrones-EFA.ipynb`

This is the main Jupyter notebook for performing exploratory data analysis (EDA) on a *Game of Thrones* dataset. The notebook includes:
- Data loading and preprocessing
- Visualization of key trends (e.g., character interactions, region statistics)
- Statistical analysis using various Python libraries


---

## Analysis Overview

The analysis focuses on exploring various dimensions of the *Game of Thrones* dataset, including:
- **Character Interactions**: Analyzing how different characters interact across seasons.
- **Seasonal Trends**: Evaluating statistics such as deaths, battles, and other key events over the seasons.
- **Visualization**: Visualizing data using bar charts, line plots, and other statistical graphics to represent trends and patterns.
